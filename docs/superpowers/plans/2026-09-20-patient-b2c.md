# Patient B2C (menu 7j + courses) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>

**Goal:** Ship an autonomous patient B2C path (`/patient`) where a logged-in patient uploads a lab PDF (or enters biomarkers), states problem/goals, and receives a saved 7-day culinary menu + grocery list — without exposing industrial method internals.

**Architecture:** Extend the existing Next.js 14 + Supabase + Anthropic app with patient-only routes, tables, and APIs. Reuse Synlab PDF parser and server-side reasoning/compose; sanitize all client responses. Practitioner surfaces stay unchanged aside from a discreet link to `/patient`.

**Tech Stack:** Next.js 14 App Router, TypeScript, Supabase (Auth + Postgres RLS + Storage), Vitest, existing `@/lib/synlab-pdf-parser` and reasoning/compose libs, Anthropic optional with deterministic fallback.

**Spec:** `docs/superpowers/specs/2026-09-20-patient-b2c-design.md`

## Global Constraints

- French UI copy; mobile-first
- Not a medical device / not a diagnosis / not a treatment — consent + disclaimer on every plan view
- **Never** send to the patient client: bottleneck ids, scores, thresholds, EBM tiers T1/T2/T3, cascade, raw classification traces, PMIDs pipeline
- Patient RLS: `auth.uid() = user_id` only; no practitioner cross-read in MVP
- Account required before plan generation (full account from start)
- Plan shape: 7 days × up to 3 meals + grouped grocery list
- Lab input: PDF parse (Synlab-first) + manual edit/entry
- YAGNI: no payments, no doctor chat, no 4-week program
- Tests: `npm test` + `npm run type-check` must stay green
- Frequent commits; open PRs against `main`

    const client = sanitizePlanForClient({
      id: 'p1',
      days: Array.from({ length: 7 }, (_, i) => ({
        day: i + 1,
        label: `J${i + 1}`,
        meals: [{ slot: 'lunch', title: 'Bol', summary: 'légumes' }],
      })),
      grocery_list: [{ aisle: 'Légumes', items: ['Courgette'] }],
      bottleneck_id: 'IR',
      scores: { IR: 9 },
      tiers: ['T1'],
      classification: { dominant: 'IR' },

    expect(client.days).toHaveLength(7);
    expect(client.grocery_list[0].items).toContain('Courgette');
    expect(JSON.stringify(client)).not.toMatch(/bottleneck|HOMA_IR threshold|T1\/T2|classification|scores/i);
    expect(client.disclaimer.length).toBeGreaterThan(10);
  });
});
